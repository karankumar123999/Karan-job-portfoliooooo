KARAN KUMAR PORTFOLIO — START HERE

1. Extract the entire ZIP into a normal folder (do not run it inside the ZIP).
2. Install Node.js LTS if it is not installed: https://nodejs.org/
3. Double-click RUN_PORTFOLIO.bat.
4. Wait until the terminal says Local: http://127.0.0.1:5173/ (or another port).
5. Open the exact Local URL printed in the terminal.

If the blank page remains:
- Stop old terminal servers with Ctrl+C.
- Close old localhost tabs.
- Start RUN_PORTFOLIO.bat again and open the new Local URL.
- Keep the terminal open while viewing the site.

This folder is a React + Vite project. Do not open index.html by double-clicking it.
